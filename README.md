# Charity-Project
This project is designed to facilitate communication between philanthropists and charity organizations. The platform allows charities to register their needs as projects, and philanthropists can browse and participate in these projects based on their skills and availability. These needs can include non-monetary assistance such as volunteer teaching, elderly or child care, and other essential skills.

<br>

## Features and System Overview
- **User Registration:** Both philanthropists and charity organizations can sign up on the platform.
- **Need Registration:** Charity organizations can define their needs as separate projects.
- **Search and Request:** Philanthropists can browse available projects and request participation.
- **Request Review and Approval:** Charity organizations can evaluate and accept or reject philanthropists' requests.
- **Project Completion:** Charity organizations can mark projects as completed once the needs are fulfilled.
